# شب‌آموز (ShabAmouz) — MVP

پلتفرم فارسی و راست‌به‌چپ (RTL) برای یادگیری **مبانی شبکه**، **دستورات CMD**، **گیت از صفر**، **لینوکس (LPIC)**، **ویندوز سرور**، **میکروتیک**، **سیسکو CCNA**، **پاورشل** و **DevOps**؛ شامل ۴۲ درس کوتاه، مرجع ۲۵ دستور در ۵ دسته با جستجو، آزمون ۱۴۰ سؤالی، ترمینال شبیه‌سازی‌شده با ۱۶ دستور (ویندوز، لینوکس، سیسکو، میکروتیک و پاورشل) و نقشه راه شغلی دو مسیره (شبکه + DevOps) هم‌راستا با مدارک جهانی.

## راه‌اندازی

```bash
npm install
npm run dev
```

سپس در مرورگر `http://localhost:3000` را باز کنید.

برای بررسی صحت TypeScript و ساخت نسخه production:

```bash
npm run build
```

## پشته فناوری

| بخش | فناوری |
|---|---|
| فریم‌ورک | Next.js (App Router) + TypeScript |
| استایل | Tailwind CSS + shadcn/ui |
| وضعیت پیشرفت | Zustand + persist (ذخیره در localStorage) |
| ترمینال | کامپوننت DOM اختصاصی شبیه ترمینال (تصمیم ۱۰؛ اجرای واقعی نداریم) |
| محتوا | فایل‌های MDX و JSON در پوشه `content/` |

## تصمیمات ثبت‌شده

طبق قانون «اگر تصمیمی مبهم بود، یک انتخاب منطقی کن و در README ثبت کن»، این موارد ثبت می‌شوند:

1. **نسخه Next.js:** در محیط اجرای این MVP، نسخه از پیش نصب‌شده Next.js (با App Router) استفاده می‌شود. پارامتر صفحات داینامیک طبق الگوی Next 15+ به‌صورت `Promise` دریافت و `await` می‌شود (الزام نسخه‌های جدید)؛ بقیه کد با قرارداد مشترک App Router نوشته شده است.
2. **Tailwind CSS 4:** پیکربندی به سبک CSS-first است (`globals.css` با `@theme`)، به‌جای `tailwind.config.js` نسخه‌های قدیمی‌تر.
3. **رندر درس‌های MDX:** درس‌ها فایل‌های `.mdx` با فرانت‌متر YAML هستند و با `react-markdown` + `remark-gfm` رندر می‌شوند. این روش از کامپایل کامل MDX در زمان اجرا پایدارتر است؛ محتوای درس‌ها Markdown استاندارد + فرانت‌متر است و فایل‌ها در `content/lessons` قابل ویرایش می‌مانند.
4. **فونت:** وزیرمتن (Vazirmatn) از طریق `next/font/google` بارگذاری می‌شود؛ بلوک‌های کد و ترمینال با فونت مونواسپیس و جهت LTR نمایش داده می‌شوند (کلاس کمکی `.ltr-content`).
5. **دستور `git` در ترمینال:** از ۱۰ اسلات دستور، یکی به `git` اختصاص یافته که زیردستورهای `status`, `add`, `commit`, `push` را می‌پذیرد تا مسیر گیت هم در ترمینال تمرین‌پذیر باشد.
6. **رنگ‌بندی:** رنگ اصلی سبز زمردی (emerald) و رنگ تاکید کهربایی؛ رنگ مسیرهای پایه: شبکه = سبزآبی (teal)، CMD = کهربایی (amber)، گیت = بنفش (violet)؛ رنگ مسیرهای سطح کارشناس/مدیریت: کارشناس شبکه = فیروزه‌ای (cyan)، مدیر شبکه = رز (rose)، کارشناس DevOps = آبی (sky)، معمار SRE = نیلی (indigo).
7. **پیشرفت کاربر:** کلید ذخیره در localStorage برابر `shabamouz-progress-v1` است؛ از فلگ `hasHydrated` برای جلوگیری از اختلاف رندر سرور/مرورگر استفاده می‌شود.
8. **اعداد فارسی:** همه اعداد UI (تعداد درس، درصد پیشرفت، نتیجه آزمون و…) با کمکی `faNum` (`toLocaleString("fa-IR")`) به رقم فارسی تبدیل می‌شوند؛ خروجی سرور و کلاینت یکسان است و mismatch ندارد.
9. **حالت فاز ۳:** در فاز ۳ دکمه «شروع آزمون» و ترمینال تعاملی عمداً غیرفعال بودند (با پیام «فاز ۴») و در فاز ۴ فعال شدند.
10. **موتور رندر ترمینال (جایگزینی xterm.js):** نسخه فعلی xterm.js (v6) از متن RTL/bidi پشتیبانی نمی‌کند و متن فارسی را ناخوانا رندر می‌کند (تست تجربی انجام شد؛ خروجی به‌هم‌ریخته بود). چون معیار پذیرش MVP خروجی فارسی خوانا (مثل `ping google.com`) است، ترمینال با یک کامپوننت DOM اختصاصی ساخته شد که ظاهر و رفتار ترمینال را کامل شبیه‌سازی می‌کند (پرامپت به‌روزشونده با cd، مکان‌نمای چشمک‌زن، تاریخچه با فلش بالا/پایین، cls، رنگ خطاها) و رندر فارسی هر سطر را به موتور bidi مرورگر می‌سپارد. جهت هر سطر خروجی خودکار تشخیص داده می‌شود (سطر دارای نویسه فارسی = RTL). بسته‌های @xterm/xterm و @xterm/addon-fit در پروژه نصب باقی‌مانده‌اند تا در صورت افزودن پشتیبانی bidi به xterm در آینده، جایگزینی ممکن باشد.
11. **نقشه راه شغلی:** بخش نقشه راه کاملاً داده‌محور است (`content/roadmap.json` با نوع‌های `RoadmapTrack` و `RoadmapLevel` در `types.ts` و لودر `getRoadmap`). چهار مرحله درخواستی (شبکه پایه، کارآموز، کارشناس، مدیر) بر اساس چارچوب رایج مدارک جهانی تنظیم شد: CompTIA (شروع بی‌طرف)، Cisco (CCNA ← CCNP ← CCIE)، Juniper و MikroTik (اکوسیستم‌های جایگزین) و ITIL برای مهارت‌های مدیریت سرویس؛ مدت‌ها تقریبی و برای یادگیری پاره‌وقت است. صفحه با طراحی تایم‌لاین عمودی RTL (نودهای شماره‌دار با سایه پله‌پله) ساخته شد و مراحل ۱ و ۲ به مسیرهای موجود شب‌آموز وصل‌اند. با ۷ لینک شدن منو، نقطه شکست ناوبری دسکتاپ از `md` به `lg` تغییر کرد تا سرریز نکند.
12. **نقشه راه چندمسیره (شبکه + DevOps):** برای افزودن مسیر شغلی DevOps بدون شکستن ساختار قبلی، `roadmap.json` به‌شکل `tracks: [network, devops]` بازطراحی شد و صفحه `/roadmap` با تب (shadcn Tabs) بین دو مسیر جابه‌جا می‌شود؛ هر مسیر هویت رنگی خودش را دارد (شبکه = زمردی، DevOps = آبی sky) و رنگ نودها در هر دو مسیر پله‌به‌پله پررنگ‌تر می‌شود. مراحل DevOps بر اساس استانداردهای جهانی تنظیم شد: LPI و Red Hat (لینوکس)، Docker و CNCF/Linux Foundation (کانتینر و CKA)، HashiCorp (Terraform)، AWS/Microsoft/Google (ابر) و الگوهای SRE گوگل (ITIL برای مدیریت سرویس). مراحل پایه DevOps به درس‌های گیت/CMD/شبکه شب‌آموز وصل شده‌اند. تب‌ها فقط UI کلاینت‌اند و محتوای هر دو مسیر در سمت سرور رندر می‌شود (SSR کامل).
13. **آموزش مراحل نقشه راه:** برای هر مرحله بدون محتوا از نقشه راه (کارشناس/مدیر شبکه و کارشناس/معمار DevOps) یک مسیر یادگیری سه‌درسی با آزمون ۱۰ سؤالی اضافه شد؛ شناسه‌ها با شناسه مرحله هم‌خوان‌اند (network-specialist، network-manager، devops-engineer، devops-architect) و در `relatedPathIds` نقشه راه وصل شده‌اند. ساختار مدل (PathId، ۳ درس هر مسیر، ترکیب ۷+۳ سؤال) بدون تغییر گسترش یافت تا همه صفحات (خانه، مسیرها، آزمون، پیشرفت) خودکار با داده جدید کار کنند؛ رنگ‌های جدید (cyan، rose، sky، indigo) به path-styles و آیکون‌های جدید (Router، Building2، Container، Workflow) به PathIcon اضافه شد.
14. **مسیرهای مدارک حرفه‌ای (LPIC/MCSA/میکروتیک/CCNA/پاورشل):** هفت مسیر یادگیری جدید برای مدارک پرتقاضای بازار کار اضافه شد: linux-lpic1، linux-lpic2، linux-lpic3 (لینوکس بر اساس آزمون‌های 101/102، 201/202 و تخصص 300 مؤسسه LPI)، mcsa (ویندوز سرور؛ با اشاره به بازنشستگی مدرک و جانشین AZ-800/801)، mikrotik (MTCNA)، ccna (آزمون 200-301) و powershell (اتوماسیون ویندوز؛ مرتبط با مسیر DevOps). هر مسیر ۳ درس MDX و ۱۰ سؤال آزمون (۷+۳) دارد؛ رنگ‌های جدید (green، emerald، lime، blue، orange، purple) به `path-styles.ts` و آیکون‌های جدید (Terminal، HardDrive، Server، AppWindow، Wifi، Cable، SquareTerminal) به PathIcon اضافه شد. نقشه راه هم به‌روز شد: مرحله «کارآموز شبکه» به CCNA و میکروتیک، «مدیر شبکه» به MCSA و LPIC-1، و مراحل DevOps به‌ترتیب سطح به LPIC-1 تا LPIC-3 و پاورشل وصل شدند؛ اعتبارسنجی محتوا به ۱۴ مسیر / ۴۲ درس / ۱۴۰ سؤال ارتقا یافت.
15. **گسترش مرجع و ترمینال همراه با مسیرهای مدارک:** مرجع دستورات از ۱۵ به ۲۵ دستور در پنج دسته رسید — دو دسته جدید «لینوکس» (ls، chmod، systemctl، ssh، apt) و «پاورشل» (Get-Command، Get-Help، Get-ChildItem، Get-Process، Get-Service) که درس‌های جدید را پشتیبانی می‌کنند؛ فیلتر دسته صفحه مرجع با نوار شمارش‌دار برای هر دسته گسترش یافت. ترمینال شبیه‌سازی‌شده هم از ۱۰ به ۱۶ دستور رسید با موتور تطبیق بدون تغییر: دستورات لینوکس (ls و ls -la، chmod با حالت‌های 755/644، systemctl با زیردستورهای status/start/restart/enable)، سیسکو IOS (show ip interface brief و show version)، میکروتیک RouterOS (/ip address print، route print، address add — موتور نام دستور با اسلش را پشتیبانی می‌کند) و پاورشل (Get-Process). فهرست help، دستورهای سریع بالای ترمینال و برگه تقلب صفحه ترمینال هم‌زمان به‌روز شدند؛ اعتبارسنجی محتوا حالا ۲۵ دستور مرجع (۵×۵ دسته) و ۱۶ قاعده ترمینال با قواعد نمونه‌ای هر خانواده را تضمین می‌کند.
16. **تمرین در حین مطالعه — ترمینال تمرینی داخل هر درس:** طبق بازخورد «بهم‌ریختگی»، ترمینال دیگر صفحه‌ای جدا نیست؛ پایین هر صفحه درس بخش «تمرین عملی همین درس» اضافه شد که فقط دستورهای مرتبط با همان مسیر را پشتیبانی می‌کند (فیلد جدید `paths` روی هر قاعده `terminal.json`؛ پوشش هر ۱۴ مسیر با اعتبارسنجی). روی هر بلوک کدِ درس که خط اولش با یکی از دستورهای همان مسیر شروع شود، دکمه «امتحان کن در ترمینال» می‌نشیند که با یک رخداد سفارشی window (`shabamouz:try-command`) دستور را در ترمینال پایین صفحه اجرا می‌کند، با اسکرول نرم و فلش سبز؛ پیشوندهای `$`/`sudo`/`PS>` و توضیح انتهای خط قبل از اجرا پاک می‌شوند. یکدست‌سازی‌های همراه: خروجی help و دستورهای cls/clear در موتور ترمینال پویا ساخته می‌شوند (نه در JSON) تا فهرست راهنما هیچ‌وقت از قواعد عقب نیفتد؛ دکمه‌های دستور سریع از فیلد جدید `example` هر قاعده می‌آیند (نه لیست دستی)؛ و پرامپت ترمینال تمرینی به خانواده فناوری مسیر حساس است — Bash (`ali@shabamouz:~$`) برای لینوکس/DevOps، IOS (`Router>`) برای سیسکو، RouterOS (`[admin@MikroTik] >`) برای میکروتیک، PowerShell (`PS C:\Users\Ali>`) برای MCSA/پاورشل. دو قاعده جدید pwd و cat هم برای پوشش کامل مسیرهای لینوکس اضافه شد (۱۶ قاعده + help/cls پویا).

## وضعیت پیاده‌سازی

- **فاز ۱ (کامل‌شده):** اسکلت پروژه، مدل داده، store پیشرفت، layout با RTL و وزیرمتن، Navbar/Footer، تم روشن/تاریک
- **فاز ۲ (کامل‌شده):** همه فایل‌های محتوا در `content/` (۳ مسیر، ۹ درس MDX، مرجع ۱۵ دستور، ۳۰ سؤال، ۱۰ دستور ترمینال) + لایه بارگذاری `src/lib/content.ts` + رندر درس با بلوک کد LTR + اسکریپت اعتبارسنجی محتوا
- **فاز ۳ (کامل‌شده):** همه صفحات: خانه داده‌محور با آمار واقعی، فهرست مسیرها، صفحه هر مسیر با نوار پیشرفت، صفحه درس با رندر Markdown و بلوک کد LTR و ناوبری قبلی/بعدی و ثبت تکمیل، مرجع ۱۵ دستور با جستجوی زنده و فیلتر دسته، آزمون (نمای مسیرها + بهترین نتیجه از store)، پیشرفت من (آمار کلی + جزئیات هر مسیر + بازنشانی) و ترمینال (پیش‌نمایش + برگه تقلب)؛ اعداد UI با رقم فارسی
- **فاز ۴ (کامل‌شده):** ترمینال شبیه‌سازی‌شده تعاملی (۱۰ دستور با خروجی فارسی از `terminal.json`، پرامپت به‌روزشونده با cd، تاریخچه دستورها، cls، دستورهای سریع و reset) + موتور کامل آزمون در `quiz/[path]` (پاسخ سؤال به سؤال، توضیح هر سؤال، نمره‌دهی، مرور پاسخ‌ها، ذخیره نتیجه در store) + اتصال کامل پیشرفت به Dashboard (بهترین درصد، تعداد تلاش، وضعیت ترمینال)
- **فاز ۵ (کامل‌شده — MVP نهایی):** پرداخت UI نهایی: صفحه ۴۰۴ فارسی، favicon اختصاصی (`icon.svg`)، تبدیل ارقام شمارنده‌های مرجع دستورات به رقم فارسی، رفع هشدار a11y منوی موبایل، و تست پذیرش کامل هر ۷ معیار با مرورگر واقعی (چک‌لیست پایین)؛ `npm run build` واقعی بدون خطا پاس شد و خروجی production (`standalone`) هم با مرورگر تست شد
- **افزوده پس از MVP (کامل‌شده):** نقشه راه شغلی ۴ مرحله‌ای (`/roadmap`): شبکه پایه ← کارآموز ← کارشناس ← مدیر، با مهارت‌ها، مدارک جهانی (CompTIA، CCNA/CCNP/CCIE، JNCIA/JNCIE، MTCNA/MTCRE، CISSP، ITIL 4)، پیش‌نیاز هر مرحله، اتصال مراحل ۱ و ۲ به درس‌های موجود و بخش مبنا؛ داده در `content/roadmap.json` + اعتبارسنجی در اسکریپت محتوا + لینک در منو/فوتر/دکمه CTA خانه
- **افزوده دوم پس از MVP (کامل‌شده):** مسیر شغلی DevOps در نقشه راه: ساختار `roadmap.json` به دو مسیر (شبکه + DevOps) تبدیل شد و صفحه `/roadmap` با تب بین دو مسیر جابه‌جا می‌شود. مراحل DevOps: پایه DevOps ← کارآموز DevOps ← کارشناس DevOps ← معمار DevOps/SRE با مدارک جهانی هر سطح (LPI Linux Essentials، RHCSA، Docker DCA، GitHub Foundations، CKA، Terraform Associate، AWS DevOps Professional / AZ-400، Google Professional Cloud DevOps Engineer، CKS، ITIL 4)؛ مراحل ۱ و ۲ DevOps به درس‌های شب‌آموز وصل شده‌اند.
- **افزوده سوم پس از MVP (کامل‌شده):** آموزش کامل مراحل نقشه راه: چهار مسیر یادگیری جدید با ۱۲ درس MDX و ۴۰ سؤال آزمون — «کارشناس شبکه» (OSPF، VPN سایت‌به‌سایت IPsec، اتوماسیون با Ansible)، «مدیر شبکه» (طراحی سه‌لایه، پایش و SLA، تیم و بودجه با ITIL)، «کارشناس DevOps» (Docker، Kubernetes، CI/CD با GitHub Actions) و «معمار DevOps/SRE» (اصول SRE و SLI/SLO، IaC با Terraform، مدیریت رخداد و پس‌نگری Blameless).
- **افزوده چهارم پس از MVP (کامل‌شده):** هفت مسیر یادگیری مدارک حرفه‌ای با ۲۱ درس MDX و ۷۰ سؤال آزمون: «لینوکس LPIC-1» (FHS و Bash، مجوزها و chmod، کاربران/systemd)، «لینوکس LPIC-2» (پارتیشن/LVM/RAID، شبکه و SSH، nginx/BIND/nftables)، «لینوکس LPIC-3» (LDAP و Samba AD، KVM و کانتینر، Ansible و FreeIPA)، «ویندوز سرور MCSA» (نصب و Core، AD و GPO، DHCP/DNS/فایل‌سرور)، «میکروتیک MTCNA» (Winbox و RouterOS، فایروال و NAT، Queue و WiFi)، «سیسکو CCNA» (VLAN و Trunk، OSPF، ACL/NAT/اتوماسیون) و «پاورشل» (Cmdlet و پایپ‌لاین، اسکریپت‌نویسی، Remoting/AD/DSC). کل پروژه الان **۱۴ مسیر، ۴۲ درس و ۱۴۰ سؤال** است؛ هر ۸ مرحله هر دو نقشه راه به محتوای شب‌آموز وصل شده‌اند (مرحله ۲ شبکه به CCNA و میکروتیک، مراحل DevOps به LPIC و پاورشل).
- **افزوده پنجم پس از MVP (کامل‌شده):** گسترش مرجع و ترمینال هم‌سو با مسیرهای مدارک: مرجع دستورات به ۲۵ دستور در ۵ دسته (افزودن دسته‌های لینوکس و پاورشل) و ترمینال شبیه‌سازی‌شده به ۱۶ دستور (افزودن ls، chmod، systemctl، show سیسکو، /ip میکروتیک و Get-Process پاورشل)؛ help، دستورهای سریع و برگه تقلب هم‌زمان به‌روز شدند.
- **افزوده ششم پس از MVP (کامل‌شده):** تمرین در حین مطالعه: بخش «تمرین عملی همین درس» با ترمینال شبیه‌سازی‌شده‌ی محدود به دستورهای همان مسیر در پایین هر ۴۲ صفحه درس + دکمه «امتحان کن در ترمینال» روی بلوک‌های کد درس (اجرای یک‌کلیکی با اسکرول و فلش سبز) + پرامپت متناسب با هر خانواده فناوری (Bash/IOS/RouterOS/PowerShell) + پویا شدن help و cls/clear در موتور ترمینال و داده‌محور شدن دستورهای سریع (فیلدهای paths و example در terminal.json و قواعد جدید pwd و cat).
