در درس قبل دیدیم که هر دستگاه برای شنیده‌شدن به یک آدرس یکتا نیاز دارد. در این درس به قلب همین موضوع می‌رویم: IP چیست، ماسک زیرشبکه چه کاری می‌کند و چرا وقتی نام سایت را تایپ می‌کنید، سیستم عامل از آن یک آدرس عددی می‌سازد.

## آدرس IP چیست؟

**IP** مخفف Internet Protocol است؛ قالب استاندارد آدرس‌دهی در شبکه‌ها. رایج‌ترین نسخه آن IPv4 است که یک عدد ۳۲ بیتی است و به‌صورت چهار بایت جدا‌شده با نقطه نوشته می‌شود:

```
192.168.1.10
```

هر کدام از چهار بخش بین صفر و ۲۵۵ می‌تواند باشد؛ به همین دلیل حدود ۴٫۳ میلیارد آدرس منحصربه‌فرد تعریف شده است. برای دستگاه‌های امروزی این تعداد کم شده و نسخه IPv6 با آدرس‌های بسیار طولانی‌تر جایگزین تدریجی آن است، اما IPv4 هنوز همه‌جا حضور دارد.

## IP خصوصی و IP عمومی

همه IPها به یک اندازه «عمومی» نیستند. یک تقسیم‌بندی مهم وجود دارد:

- **IP عمومی (Public):** آدرسی که در سطح اینترنت معتبر است و توسط ISP به شما داده می‌شود؛ مثل آدرس روتر شما از دید دنیا.
- **IP خصوصی (Private):** آدرسی که فقط داخل LAN معنا دارد و در همه شبکه‌های دنیا می‌تواند تکراری باشد.

سه بازه زیر مخصوص آدرس‌های خصوصی است و در اینترنت روتینگ نمی‌شود:

| بازه | تعداد معمول شبکه |
|---|---|
| 10.0.0.0 تا 10.255.255.255 | شبکه‌های بزرگ سازمانی |
| 172.16.0.0 تا 172.31.255.255 | شبکه‌های متوسط |
| 192.168.0.0 تا 192.168.255.255 | خانه و دفترهای کوچک |

احتمالاً IP دستگاه شما یکی از همین آدرس‌هاست؛ رایج‌ترین حالت شبکه‌های خانگی `192.168.1.x` است. این ساختار باعث شده میلیاردها دستگاه داخل شبکه‌های خصوصی، همه با یک IP عمومی مشترک به اینترنت دسترسی داشته باشند (به این تکنیک NAT گفته می‌شود).

## ماسک زیرشبکه

IP از دو بخش تشکیل شده: **بخش شبکه** (کدام شبکه) و **بخش میزبان** (کدام دستگاه داخل آن شبکه). **ماسک زیرشبکه (Subnet Mask)** مرز بین این دو بخش را مشخص می‌کند.

```
IP:       192.168.1.10
Mask:     255.255.255.0
```

در ماسک `255.255.255.0`، سه عدد اول به بخش شبکه اختصاص دارد. یعنی همه دستگاه‌هایی که با این ماسک، آدرسشان با `192.168.1` شروع شود در یک زیرشبکه هستند و بدون روتر می‌توانند مستقیم با هم حرف بزنند. بخش صفر آخر حدود ۲۵۴ آدرس قابل استفاده به میزبان‌ها می‌دهد (آدرس `.0` نام شبکه است و `.255` آدرس پخش همگانی).

پس نقش ماسک یک جمله است: «به دستگاه بگو چه کسی همسایه‌ات است و چه کسی باید از راه روتر ارسال شود».

## DNS؛ دفترچه تلفن اینترنت

شما هرگز آدرس عددی سایت‌ها را حفظ نمی‌کنید؛ نامشان را می‌نویسید. اما شبکه فقط با عدد کار می‌کند. **DNS (Domain Name System)** سیستمیه که نام دامنه را به IP ترجمه می‌کند؛ مثل دفترچه تلفنی که «رستوران مورد علاقه» را به شماره‌اش تبدیل می‌کند.

وقتی در مرورگر `google.com` را باز می‌کنید، پیش از هر چیز این زنجیره رخ می‌دهد:

1. سیستم عامل می‌پرسد: «آدرس IP مربوط به google.com چیست؟»
2. اول cache محلی چک می‌شود؛ اگر نبود، درخواست به DNS سرور تعریف‌شده در تنظیمات شبکه می‌رود.
3. DNS سرور پاسخ می‌دهد؛ مثلاً: `142.250.185.78`
4. مرورگر به آن IP درخواست می‌فرستد و صفحه باز می‌شود.

می‌توانید خودتان این ترجمه را ببینید؛ بعداً در درس ابزارها این کار را عملی انجام می‌دهیم:

```
nslookup google.com
```

اگر DNS خراب شود، اینترنت «از کار می‌افتد» در حالی که اتصال فیزیکی سالم است؛ چون شما IP می‌خواهید و شبکه نام می‌دهد. به همین دلیل یکی از اولین قدم‌های عیب‌یابی، تست DNS است.

## جمع‌بندی

- IPv4 یک آدرس چهارتکه بین صفر و ۲۵۵ در هر بخش است؛ IPv6 نسخه گسترده‌تر آن است.
- بازه‌های `10.x`، `172.16-31.x` و `192.168.x` خصوصی هستند و فقط داخل LAN معنا دارند.
- ماسک زیرشبکه تعیین می‌کند کدام بخش IP متعلق به شبکه است و کدام بخش به دستگاه.
- DNS نام دامنه را به IP ترجمه می‌کند؛ بدون آن مرورگرها کار نمی‌کنند.

برای تمرین: در درس بعد با `ipconfig` و `ping` همین مفاهیم را روی سیستم خودتان اجرا می‌کنیم.
