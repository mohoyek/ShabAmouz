خیلی‌ها خط فرمان را بازمانده دهه‌های قبل می‌دانند؛ اما واقعیت برعکس است: سریع‌ترین ابزار کار با کامپیوتر همان صفحه‌ای است که فقط متن دارد. در این درس CMD را باز می‌کنیم، می‌فهمیم پوشه جاری چیست و با سه دستور اصلی ناوبری کار می‌کنیم.

## چرا خط فرمان؟

دو دلیل اصلی که حرفه‌ای‌ها عاشق خط فرمان‌اند:

- **سرعت و دقت:** ساخت صد پوشه با ماوس یعنی صد بار کلیک؛ در خط فرمان یک سطر کد.
- **در همه‌جا موجود است:** وقتی سرور مجازی به شما داده می‌شود، معمولاً فقط یک ترمینال دارید، بدون دسکتاپ و آیکون‌ها.

ابزارهای شبکه‌ای که در مسیر «مبانی شبکه» دیدیم (`ping`، `ipconfig` و…) هم همه در همین محیط اجرا می‌شوند؛ پس یادگیری CMD به هر دو مسیر کمک می‌کند.

## باز کردن CMD

در ویندوز کافی است منوی استارت را باز کنید و بنویسید `cmd` یا `Command Prompt` و Enter بزنید. یک پنجره مشکی باز می‌شود با چیزی شبیه این:

```
C:\Users\Ali>
```

این خط **پرامپت (Prompt)** نام دارد و اطلاعات مهمی دارد: مسیر **پوشه جاری** یعنی `C:\Users\Ali` و بعد از آن مکان‌نمای تایپ. مفهوم پوشه جاری قلب کار با خط فرمان است: هر دستوری که اجرا می‌کنید، نسبت به همین پوشه عمل می‌کند؛ مثل اینکه بگویید «همین‌جا یک پوشه بساز».

## دستور dir؛ چه چیزی این‌جا هست؟

`dir` فهرست فایل‌ها و پوشه‌های پوشه جاری را نشان می‌دهد:

```
dir
```

خروجی شامل نام هر فایل، تاریخ و حجم است. دو پارامتر پرکاربرد:

```
dir /a        فایل‌های مخفی و سیستمی هم دیده می‌شوند
dir *.txt     فقط فایل‌های با پسوند txt
```

ستاره `*` یک **wildcard** است؛ یعنی «هر چیزی». `*.txt` یعنی هر نامی که با `.txt` تمام شود.

## دستور cd؛ جابه‌جایی بین پوشه‌ها

`cd` مخفف Change Directory است؛ اصلی‌ترین دستور ناوبری:

```
cd Desktop          وارد پوشه Desktop شو (مسیر نسبی)
cd C:\Windows       برو مستقیم به این مسیر (مسیر مطلق)
cd ..               برگرد به پوشه والد
cd \                برو به ریشه درایو (مثلاً C:\)
```

دو مفهوم مسیر را فرق دهید: **مسیر مطلق** از ریشه درایو شروع می‌شود و کامل است (`C:\Users\Ali\Desktop`)؛ **مسیر نسبی** نسبت به پوشه جاری است (`Desktop` یا `..\Downloads`). علامت `..` همیشه یعنی «یک پوشه بالاتر» و `.` یعنی همین پوشه.

یک نکته مخصوص ویندوز: برای جابه‌جایی بین درایوهای مختلف باید `/d` را اضافه کنید یا نام درایو را تایپ کنید:

```
cd /d D:\Projects     جابه‌جایی بین درایوها در یک دستور
D:                    یا فقط نام درایو را بزنید
```

## دستور cls؛ صفحه را تمیز کن

بعد از چند ده دستور، صفحه شلوغ می‌شود. `cls` (Clear Screen) همه خروجی‌ها را پاک می‌کند و پرامپت را بالای صفحه برمی‌گرداند. داده‌ای از بین نمی‌رود؛ فقط ظاهر صفحه تمیز می‌شود.

## جمع‌بندی

- خط فرمان سریع، دقیق و همیشه در دسترس است؛ پوشه جاری قلب کار با آن است.
- `dir` فهرست محتوا را می‌دهد و با wildcard مثل `*.txt` می‌تواند فیلتر کند.
- `cd` بین پوشه‌ها حرکت می‌کند: مسیر مطلق با `\` از ریشه، مسیر نسبی با `..` به بالا.
- `cls` صفحه را پاک می‌کند و `/d` برای جابه‌جایی بین درایوها لازم است.

برای تمرین: CMD را باز کنید، وارد `Desktop` شوید، با `dir` محتوایش را ببینید و به پوشه والد برگردید. در درس بعد همین محیط را برای ساختن و مدیریت فایل‌ها به کار می‌گیریم.
