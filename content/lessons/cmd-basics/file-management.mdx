در درس قبل یاد گرفتید در خط فرمان حرکت کنید؛ حالا وقت آن است که کارهای واقعی انجام دهید: ساختن پوشه، کپی و جابه‌جایی فایل و حذف. این دستورها همان کارهایی را می‌کنند که ماوس می‌کند، اما سریع‌تر و قابل تکرار؛ مثلاً برای ساخت ساختار پوشه‌های یک پروژه در چند ثانیه.

## ساختن پوشه با mkdir

`mkdir` (یا خلاصه‌اش `md`) پوشه جدید می‌سازد:

```
mkdir Projects
mkdir Projects\learn\network
```

خط دوم یک قابلیت جالب را نشان می‌دهد: اگر پوشه والد وجود نداشته باشد، CMD همه مسیر را یک‌جا می‌سازد. پس می‌توانید ساختار کامل را در چند سطر بریزید:

```
mkdir D:\Project\src
mkdir D:\Project\docs
mkdir D:\Project\tests
```

برای دیدن نتیجه همان‌جا `dir` بزنید؛ سه پوشه جدید می‌بینید.

## کپی با copy و جابه‌جایی با move

`copy` یک فایل را از جایی به جای دیگر می‌برد؛ اگر برای مقصد نام جدید بنویسید، عملاً یک نسخه با نام جدید ساخته می‌شود:

```
copy note.txt backup.txt          یک نسخه با نام جدید ساخته می‌شود
copy note.txt D:\Backup           کپی به یک پوشه دیگر با همان نام
move report.doc D:\Archive        جابه‌جایی؛ فایل از مبدأ حذف می‌شود
```

فرق copy و move یک جمله است: copy مبدأ را نگه می‌دارد، move برمی‌دارد.

با wildcard می‌توانید گروهی از فایل‌ها را هم‌زمان مدیریت کنید:

```
copy *.png D:\Pictures           همه تصاویر png را کپی کن
copy report?.txt D:\Backup       report1.txt و report2.txt و... ولی نه report10.txt
```

علامت `?` دقیقاً یک کاراکتر را جایگزین می‌کند؛ `*` هر تعداد کاراکتر را.

## حذف با del و rmdir

دو دستور متفاوت برای دو نوع شیء داریم:

- `del` برای **فایل‌ها**
- `rmdir` (یا خلاصه `rd`) برای **پوشه‌ها**

```
del note.txt                     حذف یک فایل
del *.tmp                        حذف همه فایل‌های tmp در پوشه جاری
rmdir OldFolder                  حذف پوشه‌ی خالی
rmdir /s /q OldFolder            حذف پوشه همراه با همه محتوایش، بدون سوال
```

پارامتر `/s` یعنی کل محتویات پوشه هم حذف شود و `/q` یعنی بدون سوال. این ترکیب قدرتمند و خطرناک است: فایل‌های حذف‌شده با این روش به Recycle Bin نمی‌روند و مستقیم پاک می‌شوند. همیشه قبل از اجرا، با `dir` چک کنید در پوشه درستی هستید؛ یک حرف اشتباه در مسیر می‌تواند پوشه اشتباهی را پاک کند.

## تغییر نام با ren

`ren` (Rename) نام فایل یا پوشه را عوض می‌کند؛ جابه‌جایی نیست، فقط نام:

```
ren draft-v1.txt draft-v2.txt
ren *.jpeg *.jpg                 پسوند همه فایل‌های jpeg را به jpg تغییر بده
```

## یک سناریوی کامل

همه چیز را در یک سناریوی واقعی جمع می‌کنیم؛ ساخت قالب پروژه‌ای جدید:

```
cd /d D:\
mkdir ShabamouzTest
cd ShabamouzTest
mkdir src docs
copy NUL readme.txt
dir
```

نتیجه: پوشه‌ای با دو زیرپوشه و یک فایل خالی `readme.txt`؛ همه این کارها با ماوس چند دقیقه طول می‌کشید، در خط فرمان کمتر از ده ثانیه. نکته جالب خط `copy NUL readme.txt`: چون CMD دستور «ساخت فایل خالی» جدا ندارد، از ترفند کپی دستگاه خاص `NUL` استفاده می‌شود؛ یک کلاسیک ویندوزی.

## جمع‌بندی

- `mkdir` پوشه می‌سازد و می‌تواند کل مسیر چندسطحی را یک‌جا بسازد.
- `copy` نسخه‌ای نگه می‌دارد و `move` منتقل می‌کند؛ wildcard یعنی `*` و `?` روی گروهی از فایل‌ها کار می‌کنند.
- `del` فقط فایل را حذف می‌کند؛ `rmdir /s /q` پوشه را با همه محتوایش و بدون سوال حذف می‌کند، پس با احتیاط استفاده شود.
- `ren` نام را عوض می‌کند و حتی می‌تواند پسوند گروهی از فایل‌ها را تغییر دهد.

برای تمرین: در یک پوشه آزمایشی روی دسکتاپ، سناریوی کامل بالا را اجرا کنید و بعد با `rmdir /s /q` همه‌چیز را پاک کنید. در درس بعد دستورات شبکه CMD را بررسی می‌کنیم.
